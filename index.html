    အခု မိုးကုပ်အတွင်းမှာ ရှိတယ် · Overhead now

    အနီးဆုံး ဂြိုလ်တုကို အပေါ်ဆုံးမှာ highlight နဲ့ ပြထားပြီး ကျန်တာကို Elevation အမြင့်ဆုံးကနေ စီထားတယ်။ စာရင်းမှာ အများဆုံး 120 လုံးပဲ ပြတယ် — ခေါင်းစဉ်က (ပြထားတာ / စုစုပေါင်း) နဲ့ အရေအတွက်အပြည့်ကို အပေါ်က stat မှာ ကြည့်ပါ။ Elevation 10° အထက်ဆို မြင်နိုင်ခြေ ပိုကောင်းတယ်။

      ဒီစစ်ထုတ်မှုနဲ့ အခု မိုးကုပ်အတွင်း ဂြိုဟ်တု မရှိသေးပါ။ ခဏစောင့်ရင် LEO ဂြိုဟ်တုတွေ ဆက်တိုက် ဝင်လာပါလိမ့်မယ်။

      Tiangong (CSS) · တရုတ် အာကာသစခန်း

      NORAD 48274 · TIANHE module · အမြင့် ~390 km

      တွက်နေတယ်…

      နောက် 48 နာရီအတွင်း Elevation 10° အထက် ဖြတ်သန်းမှုကို SGP4 နဲ့ ရှာနေတယ်။

      ဒီည မျက်စိနဲ့ မြင်ရမယ့် ဖြတ်သန်းမှုများ · Visible passes

      မျက်စိနဲ့ တကယ်မြင်ရဖို့ အခြေအနေ ၂ ခု တပြိုင်နက် လိုတယ် — (၁) ဂြိုလ်တုကို နေရောင်ထိနေရမယ် (ကမ္ဘာ့အရိပ်ထဲ ဝင်နေရင် မမြင်ရပါ)၊ (၂) မင်းနေရာမှာ မှောင်နေရမယ် (ညနေ ဆည်းဆာ / ည / အရုဏ်)။ အောက်က စာရင်းက အဲ့ဒီ ၂ ခုလုံး ကိုက်တဲ့ pass တွေပဲ — နောက် ၂၄ နာရီအတွင်း။ တောက်ပမှုက အကွာအဝေးနဲ့ အမြင့်ထောင့်ပေါ် မူတည်တဲ့ ခန့်မှန်းချက် ပဲ။

      တိမ်အခြေအနေ: ယူနေတယ်… (Open-Meteo)

        နောက် ၂၄ နာရီအတွင်း မျက်စိနဲ့ မြင်နိုင်တဲ့ ISS / Tiangong pass မရှိပါ — ဂြိုလ်တု နေရောင်မထိတဲ့ အချိန် (သို့) နေ့ဘက် pass တွေချည်း ဖြစ်နေလို့ပါ။ မနက်ဖြန် ပြန်စစ်ပါ။

        Ground Track · မြေပုံပေါ်က လမ်းကြောင်း

        ဂြိုလ်တုက ကမ္ဘာပေါ် ဘယ်နေရာရဲ့ အပေါ်တည့်တည့်မှာ ရှိနေလဲ (sub-point) နဲ့ orbit လမ်းကြောင်းကို latitude/longitude ဇယားကွက်ပေါ် ဆွဲပြထားတာ။ အစက်ကြီး = အခု တည်နေရာ · လိုင်း = အရင် ~၅၀ မိနစ် + နောက် ~၁၀၀ မိနစ် လမ်းကြောင်း။ အဝါရောင် ◎ = မင်းနေရာ။ ရွေးထားတဲ့ ဂြိုလ်တုကိုလည်း အဖြူလိုင်းနဲ့ ပြတယ်။

        ISS လမ်းကြောင်း Tiangong လမ်းကြောင်း ရွေးထားသော ဂြိုလ်တု

        Signal နားထောင်ခြင်း · Receive Signals

        ဂြိုလ်တုနဲ့ “ချိတ်” တာ မဟုတ်ဘူး — ဂြိုလ်တု ထုတ်လွှင့်နေတဲ့ ရေဒီယို signal ကို ဖမ်းနားထောင်တာ / ပုံဒေါင်းတာ ပဲ။ အောက်က စာရင်းက အခု သင့်ခေါင်းပေါ်မှာ တကယ်ရှိနေတဲ့ လက်ခံနိုင်တဲ့ ဂြိုလ်တုတွေကို live TLE နဲ့ တွက်ပြထားတာ။

        အမှန်အတိုင်း ပြောရရင်: ဒီ website ကိုယ်တိုင်က signal ဖမ်းလို့ မရပါဘူး။ ဖုန်း / browser မှာ SDR receiver မပါလို့ webpage က 137 MHz / 145 MHz ကို တိုက်ရိုက် နားထောင်လို့ မရပါ။ ဒီ page က လုပ်ပေးနိုင်တာက — ဘယ်ဂြိုလ်တု၊ ဘယ် frequency နဲ့၊ ဘယ်အချိန် ခေါင်းပေါ်ရောက်ပြီး ဖမ်းဖို့ အကောင်းဆုံးလဲ ဆိုတာကို live ပြပေးတာပဲ။ တကယ် ဖမ်းဖို့က အောက်က ပစ္စည်းတွေ လိုတယ်။

        အခု ဖမ်းလို့ရနိုင်တဲ့ ဂြိုလ်တုများ · Receivable now

        Elevation ≥ 10° ဆို အခု လက်ခံနိုင်တယ် · 0–10° ဆို အနားသတ်နားမို့ အားနည်းနိုင်တယ် · အောက်ရောက်နေရင် နောက်ဖြတ်ချိန် စောင့်ပါ။

          TLE data ရရင် NOAA / METEOR / ISS နဲ့ အပျော်တမ်း ဂြိုလ်တုတွေရဲ့ live အနေအထား ဒီမှာ ပေါ်မယ်။

          ဘယ်လို ဖမ်းရမလဲ · Practical guide

          ၁) လိုအပ်တဲ့ ပစ္စည်းတွေ

          RTL-SDR dongle (USB)RTL2832U + R820T2 — 24 MHz–1.7 GHz ဖမ်းနိုင်တယ်၊ စျေးအသက်သာဆုံး အစပဲ။
          Antenna — V-dipole (137 MHz)အလျား ~53 cm စီ ၂ ချောင်း၊ 120° ခွဲထားတဲ့ V ပုံ — NOAA / METEOR အတွက် အခြေခံ။ ပိုကောင်းချင်ရင် QFH antenna သုံး။
          Computer / Phone + SDR appLaptop: SDR++ / SDR# · Android: SDR++ / RF Analyzer (OTG နဲ့ dongle ချိတ်)။
          Software — SatDumpNOAA APT ပုံ decode + METEOR LRPT ပုံအတွက် အခမဲ့။ ISS SSTV အတွက် Robot36 (Android) / MMSSTV။

          ၂) ဖမ်းနည်း အဆင့်ဆင့် (NOAA ဥပမာ)

          1. ဒီ page မှာ NOAA 15/18/19 တစ်ခုခု Elevation မြင့်တဲ့ အချိန် (≥ 30° အကောင်းဆုံး) ကို ရွေးပြီး အချိန်မှတ်။
          2. အပြင် ကျယ်ကျယ် / ခေါင်မိုးပေါ်မှာ V-dipole ကို အလျားလိုက်၊ V ကို တောင်ဘက်ချိန် ထားပါ။ အတားအဆီးနည်းလေ ပိုကောင်းလေ။
          3. SDR app မှာ frequency ချိန် — ဥပမာ NOAA 19 ဆို 137.100 MHz၊ mode WFM၊ bandwidth ~34–40 kHz၊ gain 35–45 dB ပတ်လည် စမ်းပါ။
          4. ဂြိုလ်တု တက်လာတာနဲ့ “tick-tock” APT အသံ / waterfall မှာ signal လိုင်း ထင်းလာမယ် — တစ် pass လုံး (၁၀–၁၅ မိနစ်) Record လုပ်ထားပါ။ Doppler ကြောင့် frequency အနည်းငယ် ရွေ့တာ ပုံမှန်ပဲ။
          5. Record ဖိုင်ကို SatDump → NOAA APT pipeline မှာ ထည့်ပြီး decode လုပ်ရင် မိုးတိမ် ဓာတ်ပုံအစစ် ရမယ်။ METEOR ဆိုရင် SatDump → METEOR LRPT (137.100 / 137.900 MHz, QPSK) သုံး။
          6. ISS SSTV ဆိုရင် 145.800 MHz FM ကို ဖမ်းပြီး Robot36 နဲ့ ပုံပြန်ထုတ်။ ISS voice repeater / APRS (145.825 MHz) လည်း နားထောင်လို့ရတယ်။

          ၃) သိထားရမှာတွေ

          • Receive-only: နားထောင်တာ / ပုံယူတာပဲ — ဂြိုလ်တုကို ထိန်းချုပ်တာ၊ ချိတ်တာ၊ command ပို့တာ လုံးဝ မဟုတ်ပါ၊ လုပ်လို့လည်း မရပါ။
          • ထုတ်လွှင့်ခြင်း (transmit): ကိုယ်က ပြန်လွှင့်ချင်ရင် amateur radio licence လိုတယ်။ Licence မရှိဘဲ ထုတ်လွှင့်တာ မလုပ်ပါနဲ့။ ဖမ်းနားထောင်တာကတော့ ယေဘုယျအားဖြင့် ရတယ်။
          • Antenna ကို ကောင်းကင်ရှင်းတဲ့နေရာထားတာ၊ pass အမြင့်ဆုံးအချိန်ကို ရွေးတာ — ဒီ ၂ ခုက ပုံကောင်းရဖို့ အဓိကပဲ။

          Data source: TLE (Two-Line Elements) — CelesTrak (NORAD catalog), browser ကနေ တိုက်ရိုက် fetch လုပ်ထားတာ။ Fetched: — · TLE epoch: — တည်နေရာတွက်ချက်မှု: SGP4 propagator — satellite.js v5.0.0, သင့် browser ထဲမှာပဲ တွက်တယ်။ တိမ်အခြေအနေ: Open-Meteo forecast (နာရီအလိုက် cloud cover %)။ နေရောင်ထိ/အရိပ် တွက်ချက်မှုက browser ထဲမှာပဲ Sun position နဲ့ cylindrical shadow model နဲ့ တွက်တယ် — တောက်ပမှုက ခန့်မှန်းချက်ပဲ။

          တိကျမှု မှတ်ချက်: TLE + SGP4 တည်နေရာဟာ ပုံမှန်အားဖြင့် ကီလိုမီတာ အနည်းငယ်အတွင်း တိကျတယ် — ကောင်းကင်မှာ မျက်စိနဲ့ လိုက်ကြည့်ဖို့ လုံလောက်ပေမယ့် navigation အဆင့် မဟုတ်ပါ။ Fetch မအောင်မြင်ရင် အတု တည်နေရာ လုံးဝ မပြပါ — error ပြပြီး ပြန်ကြိုးစားခိုင်းပါတယ်။ ကြည်လင်တဲ့ ညနေ/မနက်ခင်းမှာ ISS နဲ့ Tiangong ကို အလင်းဝင်းဝင်း အစက်တစ်ခုအနေနဲ့ သာမန်မျက်စိနဲ့ မြင်နိုင်တယ်။
